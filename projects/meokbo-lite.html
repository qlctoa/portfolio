삼킴장애 환자 식사 모니터링 앱
meokbo-lite

작업치료사로 근무하며 삼킴장애(연하장애) 환자와 보호자가 안전한 식사 자세와 음식 물성을 스스로 확인하기 어려워하는 모습을 자주 접했습니다.
meokbo-lite는 카메라 기반 자세 인식과 식사 기록 기능으로 이러한 어려움을 보조하기 위해 기획한 개인 사이드 프로젝트입니다.

👤 역할 기획 · 풀스택 개발 (1인)
🏷️ 유형 Mobile Web App
🚀 상태 개인 사이드 프로젝트
🛠️ 사용 기술 React · Next.js · TypeScript

Project Overview

임상 현장에서 삼킴장애 환자와 보호자를 만날 때마다 "지금 이 자세가 맞는지", "이 정도 굳기의 음식을 먹어도 되는지"를 매 끼니 스스로 판단하기 어려워하는 경우를 자주 보았습니다. meokbo-lite는 이러한 어려움을 카메라 기반 기술로 보조하기 위해 기획한 서비스로, 진단이나 치료를 대체하지 않고 보호자가 일상에서 참고할 수 있는 보조 도구를 목표로 합니다.

Key Features

📷 자세 확인

카메라로 턱 당김(chin tuck) 자세를 인식하고, 식사 중 자세 유지 여부를 실시간으로 추적합니다.

🍚 저작 상태 감지

턱 움직임과 삼킴 패턴을 분석해 씹는 상태와 삼킴 시점을 감지합니다.

📝 식사 세션 기록

식사 시간, 자세 유지 시간, 자세 이탈 횟수를 세션 단위로 자동 기록합니다.

📅 식사 통계 캘린더

홈 화면 캘린더에서 일간·월간 식사 기록을 한눈에 확인할 수 있습니다.

🥣 음식 물성 가이드

국내 식약처 IDDSI 4~6단계 기준에 맞춘 참고 음식 예시와, 이미지 균일도·입자 분석 기반 물성 가이드를 제공합니다.
